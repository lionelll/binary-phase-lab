# 材科基 · 二元相图动态交互实验室

面向《材料科学基础》课程的纯前端交互教学网页，使用原生 SVG 绘制并计算 Cu–Ni、Pt–Ag、Pb–Sn 和 Fe–Fe₃C 四套二元相图。

## 功能

- 四套教材型二元相图切换
- 成分与温度二维拖点、滑块和数值输入联动
- 相区判定、真实等温线交点与杠杆定律
- 右栏显微组织判定及组织组成物相对含量
- 包晶、共晶、共析反应教学解析
- 自动凝固、关键反应暂停/继续与相分数显示
- 冷却路径显示相界穿越点、关键温度与三相反应公式
- 跨相图统一的单相基础色、确定性两相混色与相色图例
- 桌面、平板与移动端响应式布局

## 本地运行

```bash
npm install
npm run dev
```

Vite 基路径固定为 `/binary/`，本地地址通常为 `http://127.0.0.1:5173/binary/`。

## 验证

```bash
npm test
npm run build
```

Pt–Ag 固溶度线审计使用跨越相界容差内外的宽窗口采样，同时覆盖相区内部与临界状态；脚本使用独立 TypeScript 配置，不参与生产构建：

```bash
npm run audit:ptag-solvus
```

首页尚未完成，当前顶栏暂不显示“返回首页”入口；`VITE_PORTAL_URL` 配置保留供后续恢复入口时使用。
正式上线前必须由产品所有者确认并替换该入口地址；本项目当前不包含部署配置。

## 界面一致性

顶部品牌栏、三栏比例、中央标题栏和响应式缩放规则统一记录在 [`docs/ui-master-control.md`](docs/ui-master-control.md)。修改这些共享尺寸时，应优先调整 `src/styles.css` 末尾的主控变量，并以晶体结构实验室为视觉基准复核。
