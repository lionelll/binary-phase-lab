# 相图数据来源与取值说明

## 总则

相界形态、相区比例与标签布局以同级 PRD《二元相图动态交互实验室PRD文档【2026.8.13.1】》内嵌教材图为几何权威。运行时不使用教材图片，所有曲线均由本项目记录的控制点经单调三次插值生成。

控制点按成分递增记录；存在不同走向的边界拆分为独立分支。不变量温度与成分为硬锚点，不参与平滑修正。

## 与 PRD 的明示偏离

下列两项是与 PRD 文字不一致的**有意取舍**，均已在对应小节记录理由。严格验收时应对照本节，并在封板版 PRD 中正式载明，否则仍会被计为偏差。

| 编号 | 涉及条款 | PRD 文字 | 本项目取值 | 依据 |
|---|---|---|---|---|
| 例外一 | 6.2 / 第七节 | 教材图 A 点画在 1800℃ | Pt 真实熔点 1769℃ | PRD 7.1 优先级第二级「材料学理论规律」 |
| 例外二 | 6.4 / 第七节 | `δ-Fe / γ-Fe / α-Fe` | 图面标注 `δ / γ / α` | PRD 第七节「参考图复刻要求（最高优先级）」，教材图本身即希腊字母 |

除上述两项外，未对 PRD 的相图结构、关键温度、关键成分与反应方向作任何偏离。

## Cu–Ni 匀晶

- 成分：0–100 wt.% Ni；温度显示范围：800–1550℃。
- 端点：Cu 1085℃、Ni 1455℃。
- 中间控制点根据 PRD 匀晶参考图的液相线、固相线形态数字化并进行教学型平滑；两线仅在纯组元端点相交。

## Pt–Ag 包晶

- 成分：0–100 wt.% Ag；温度显示范围：400–1800℃。
- 纯组元端点：Pt 1769℃、Ag 962℃。
- **对 PRD 7.1 优先级的明示例外（例外一）**：PRD 教材图纵轴上限标到 1800℃、A 点视觉上贴近顶端；本项目保留铂的真实熔点 1769℃，不将 A 点改为坐标轴上限。依据为 PRD 7.1 优先级中的第二级「材料学理论规律」，属对第一级「用户参考图片」的有意偏离，需在封板版 PRD 6.2 中正式载明。
- 包晶锚点：1186℃；α 10.5% Ag、β 42.4% Ag、L 66.3% Ag。
- 反应固定为 `L + α → β`。

## Pb–Sn 共晶

- 成分：0–100 wt.% Sn；温度显示范围：0–350℃。
- 纯组元端点：Pb 327℃、Sn 232℃。
- 共晶锚点：183℃；α 19% Sn、L 61.9% Sn、β 97.5% Sn。
- 反应固定为 `L → α + β`。

## Fe–Fe₃C 亚稳相图

- 成分：0–6.69 wt.% C；温度显示范围：600–1600℃。
- Fe₃C 化学计量成分按现代原子量计算约为 6.688 wt.% C，本项目依国内主流教材显示为 6.69%。
- 包晶：1495℃，δ 0.09%、γ 0.17%、L 0.53%，反应 `L + δ → γ`。
- 共晶：1148℃，γ 2.11%、L 4.30%、Fe₃C 6.69%，反应 `L → γ + Fe₃C`。
- 共析：727℃，α 0.0218%、γ 0.77%、Fe₃C 6.69%，反应 `γ → α + Fe₃C`。
- G(0, 912℃) 至 P(0.0218%, 727℃) 的 GP 线用于区分 α 与 α+γ 区，和 A3、α 溶解度线共同闭合低碳侧相区。
- 右端 1227℃按亚稳 Fe–Fe₃C 教学图端点处理，不将其表述为现实条件下独立渗碳体的平衡熔点。
- **对 PRD 6.4 措辞的明示例外（例外二）**：PRD 6.4 要求显示 `δ-Fe / γ-Fe / α-Fe`，而 PRD 内嵌的铁碳教材参考图上标注为希腊字母 `δ / γ / α`。PRD 第七节标题为「参考图复刻要求（最高优先级）」，故图面标注按参考图采用希腊字母；`δ-Fe` 等全称仅在正文与文档中使用。需在封板版 PRD 6.4 中统一表述。
- α 溶解度线（PQ 线，600–727℃）分隔的是 α 与 α+Fe₃C 两区；GP 线分隔的才是 α 与 α+γ。两条线的相邻相区声明由自动化测试逐条比对守护。
