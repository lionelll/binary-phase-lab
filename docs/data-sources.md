# 相图数据来源与取值说明

## 总则

相界形态、相区比例与标签布局以同级 PRD《二元相图动态交互实验室PRD文档【2026.8.13.1】》内嵌教材图为几何权威。运行时不使用教材图片，所有曲线均由本项目记录的控制点经单调三次插值生成。

控制点按成分递增记录；存在不同走向的边界拆分为独立分支。不变量温度与成分为硬锚点，不参与平滑修正。

## Cu–Ni 匀晶

- 成分：0–100 wt.% Ni；温度显示范围：800–1550℃。
- 端点：Cu 1085℃、Ni 1455℃。
- 中间控制点根据 PRD 匀晶参考图的液相线、固相线形态数字化并进行教学型平滑；两线仅在纯组元端点相交。

## Pt–Ag 包晶

- 成分：0–100 wt.% Ag；温度显示范围：400–1800℃。
- 纯组元端点：Pt 1769℃、Ag 962℃。
- PRD 教材图纵轴上限标到 1800℃，A 点视觉上贴近顶端；本项目保留铂的真实熔点 1769℃，因此 A 点不强行改为坐标轴上限。
- 包晶锚点：1186℃；α 10.5% Ag、β 42.4% Ag、L 66.3% Ag。
- 反应固定为 `L + α → β`。

## Pb–Sn 共晶

- 成分：0–100 wt.% Sn；温度显示范围：0–350℃。
- 纯组元端点：Pb 327℃、Sn 232℃。
- 共晶锚点：183℃；α 19% Sn、L 61.9% Sn、β 97.5% Sn。
- 反应固定为 `L → α + β`。

## Fe–Fe₃C 亚稳相图

- 成分：0–6.69 wt.% C；温度显示范围：600–1600℃。
- Fe₃C 化学计量成分按现代原子量计算约为 6.688 wt.% C，本项目依国内主流教材显示为 6.69%。
- 包晶：1495℃，δ 0.09%、γ 0.17%、L 0.53%，反应 `L + δ → γ`。
- 共晶：1148℃，γ 2.11%、L 4.30%、Fe₃C 6.69%，反应 `L → γ + Fe₃C`。
- 共析：727℃，α 0.0218%、γ 0.77%、Fe₃C 6.69%，反应 `γ → α + Fe₃C`。
- G(0, 912℃) 至 P(0.0218%, 727℃) 的 GP 线用于区分 α 与 α+γ 区，和 A3、α 溶解度线共同闭合低碳侧相区。
- 右端 1227℃按亚稳 Fe–Fe₃C 教学图端点处理，不将其表述为现实条件下独立渗碳体的平衡熔点。
